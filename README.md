# مُدقِّق — Mudaqqiq · Arabic writing assistant (prototype)

> **الدليل الكامل خطوة بخطوة (بالإنجليزية): [GUIDE.md](GUIDE.md)**. التشغيل بملفات ‎`.bat`‎ دون أوامر.

مساعد للكتابة العربية يكتشف أخطاء **الترقيم** ويتعرّف على **الأساليب النحوية** ويقترح **التصحيح النحوي والإملائي** مع **شرح سبب كل تصحيح**، ويعمل في أربعة أماكن بالمحرّك نفسه:

| أين | المجلد | الحالة |
|---|---|---|
| موقع تجريبي (الكتابة والتصحيح مباشرة) | `web/` | مُختبَر، مع نموذجَي ذكاء اصطناعي |
| إضافة Microsoft Word (لوحة جانبية) | `word-addin/` | البيان صالح، والمنطق مُختبَر على محاكاة لواجهة Word |
| إضافة Google Docs (لوحة جانبية) | `gdocs-addon/` | مُختبَرة على محاكاة لخدمات Google |
| إضافة للمتصفح (Gmail، واتساب ويب، أي مربع نص) | `extension/` | القواعد مُختبَرة، والذكاء الاصطناعي يعمل دون إنترنت داخل الإضافة |
| تقييم الدقة على بيانات حقيقية | `eval/` | النتائج في [docs/EVALUATION.md](docs/EVALUATION.md) |

كل المعالجة تتم **على جهاز المستخدم** (لا خادم): القواعد بلغة JavaScript، ونموذج الذكاء الاصطناعي يعمل داخل المتصفح عبر ONNX Runtime Web.

---

## التشغيل

```bash
npm start            # يشغّل خادمًا محليًا على http://localhost:8080
```
ثم افتح **http://localhost:8080/web/**. يمكن بدلًا من ذلك: `python -m http.server 8080`.

> نموذج الذكاء الاصطناعي (135 م.ب) موجود في `web/models/arabic-punctuation/`. إن لم يكن موجودًا أعد إنشاءه:
> `pip install torch "transformers<5" onnx onnxruntime` ثم `python tools/export_onnx.py`

الاختبارات: `npm test` (38 اختبارًا: أمثلة الفكرة + جمل صحيحة يجب ألا تُعلَّم).

### إضافة Word
تحتاج Word إلى HTTPS. مرة واحدة على الجهاز:
```bash
npx office-addin-dev-certs install
```
(يطلب الموافقة على تثبيت شهادة تطوير محلية.) ثم:
```bash
npx http-server . -p 3000 -S -C %USERPROFILE%/.office-addin-dev-certs/localhost.crt -K %USERPROFILE%/.office-addin-dev-certs/localhost.key
```
وبعدها في Word: **إدراج ← الوظائف الإضافية ← تحميل وظيفتي الإضافية** واختر `word-addin/manifest.xml`
(أو `npx office-addin-debugging start word-addin/manifest.xml desktop`).
للنشر الدائم: ارفع المشروع على GitHub Pages واستبدل `https://localhost:3000` في `manifest.xml` برابط الموقع.

### إضافة المتصفح
```bash
npm run build:ext
```
ثم في Chrome/Edge: `chrome://extensions` ← تفعيل «وضع المطوّر» ← **Load unpacked** ← اختر مجلد `extension/`.

## ما الذي يفعله (مقابل قائمة المتطلبات)

| # | المتطلب | التنفيذ |
|---|---|---|
| 1 | يعمل أثناء الكتابة | الموقع يحلّل بعد كل ضغطة (120 ms)، وWord يفحص الفقرة الحالية عند تحرّك المؤشر، والإضافة تفحص أي مربع نص |
| 2 | Word والتطبيقات الأخرى | إضافة Word + إضافة متصفح لكل المواقع |
| 3 | الترقيم الناقص والخاطئ | علامات الترقيم الثلاث عشرة كلها: النقطة، الفاصلة، الفاصلة المنقوطة، النقطتان، الاستفهام، التعجب، التنصيص، الشرطة، الشرطتان، الأقواس الهلالية والمعقوفة والمزهرة، علامة الحذف — مع نموذج الذكاء الاصطناعي للفواصل والجمل المتصلة |
| 4 | الأساليب النحوية | الأساليب الاثنان والعشرون كلها (النداء، المدح، الذم، الاستفهام، التعجب، الأمر، النهي، النفي، التفضيل، الشرط، الاختصاص، الإغراء، التحذير، التوكيد، القسم، الندبة، التخصيص، الاستثناء، الاستغاثة، الترجي، التمني، الاشتغال)، وتبويب «الدليل» يعرّف كل أسلوب بمثال |
| 5 | التصحيح النحوي والإملائي | مطابقة الخبر للمبتدأ/اسم إنّ، نصب اسم إنّ ورفع خبرها (جمع المذكر)، اسم الإشارة، الاسم الموصول، تأنيث الفعل |
| 6 | شرح «لماذا» | كل اقتراح يحمل شرحًا عربيًا، وزر «💡 لماذا؟» |
| 7–8 | تطبيق / تجاهل | أزرار في النافذة الصغيرة بجانب الكلمة وفي القائمة؛ التطبيق يدعم التراجع Ctrl+Z |
| 9 | إضافة قواعد لاحقًا | `engine/custom-rules.js` (قاعدة = كلمة/تعبير + بديل + شرح، بلا برمجة)، والقوائم في `engine/lexicon.js` |
| 10 | ذكاء اصطناعي لاحقًا | `engine.addProvider()` — نموذج الترقيم مُضاف فعلًا، ويمكن إضافة نموذج آخر بالواجهة نفسها |

### أمثلة الفكرة
| المُدخل | الناتج |
|---|---|
| كيف حالك. | كيف حالك؟ |
| ما أجمل السماء | ما أجمل السماء! |
| هل حضرت المحاضرة. | هل حضرت المحاضرة؟ |
| يا محمد ادرس دروسك | يا محمد، ادرس دروسك. |
| إن الطالبات مجتهدون. | إن الطالبات مجتهدات. |
| السلام عليكم كيف حالك اليوم أتمنى أن تكون بخير *(بالذكاء الاصطناعي)* | السلام عليكم، كيف حالك اليوم؟ أتمنى أن تكون بخير. |

## البنية

```
engine/        المحرّك المشترك (JavaScript بلا اعتماديات) + engine/ai (نموذجا الذكاء الاصطناعي)
web/           الموقع التجريبي
word-addin/    إضافة Word
gdocs-addon/   إضافة Google Docs
extension/     إضافة المتصفح
eval/          تقييم الدقة على بيانات حقيقية
tools/         تصدير النماذج إلى ONNX، رفعها إلى Hugging Face، بناء الإضافات، إعداد الرابط العام
tests/         اختبارات المحرّك + صفحات اختبار للإضافات
docs/          ANALYSIS.md (التصميم واختيار النماذج) و EVALUATION.md (نتائج الدقة)
```

الدليل الكامل خطوة بخطوة: [GUIDE.md](GUIDE.md).
